# Data Sources and Limitations

## Annual pilot series
`data/fdi_annual_dataset.csv` includes annual FDI equity inflow values in USD million for FY 2000–01 to FY 2024–25. The values were transcribed from the financial-year-wise FDI equity section of the DPIIT Quarterly Fact Sheet on FDI Inflow.

- DPIIT: https://www.dpiit.gov.in/
- Open Government Data catalogue: https://www.data.gov.in/catalog/foreign-direct-investment-fdi-equity-inflows

## User-provided workbook
The supplied workbook contains cumulative sector-wise FDI totals over a long period. It is useful for sector context but is not a quarterly time series and must not be used as if each row were one quarter.

## Missing inputs for the assigned quarterly experiment
- Official quarterly FDI equity observations, or monthly observations with documented quarter aggregation.
- A matching RBI USD/INR exchange-rate series.
- Dated and sourced policy-event indicators.

RBI Database on Indian Economy: https://data.rbi.org.in/

No annual values have been divided into four artificial quarters. No exchange-rate or policy-event values have been invented. The attached journal PDF is an annual pilot draft, not the final quarterly submission.
